# rajabi2001.github.io

GitHub Pages site for [rajabi2001](https://github.com/rajabi2001). The root URL redirects to the primary academic homepage.

## URLs (after publish)

| Path | Purpose |
|------|---------|
| `/` | Redirects to [http://www.cs.toronto.edu/~rajabi/](http://www.cs.toronto.edu/~rajabi/) |
| `/tpg/` | Token Perturbation Guidance project page — edit files under `tpg/` |
| `/sega/` | SEGA project page — edit files under `sega/` |

## Layout

- **`index.html`** — root redirect only.
- **`assets/`** — shared static files for GitHub-hosted subsites (e.g. `academic-base.css`, optional images under `assets/images/`).
- **`tpg/`** — subsite for `/tpg/`; add `index.html`, local `style.css`, images, etc. here.
- **`sega/`** — subsite for `/sega/`; same idea, kept separate from `tpg/`.

Template credit: stylesheet derived from [Jon Barron’s academic site template](https://jonbarron.info/).
